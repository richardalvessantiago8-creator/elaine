# ELAINE AI

Protótipo inicial da nova IA ELAINE.

## O que já funciona
- Interface futurista responsiva
- Avatar feminino/masculino por referência
- Seletor de roupas
- Cor do tema
- Nome do avatar
- Chat local de demonstração
- Estrutura pronta para conectar uma API de IA real

## Como abrir
Abra `index.html` no navegador.

## Próxima etapa
Para a Elaine realmente responder com uma IA generativa, será necessário conectar um backend/API. Não coloque uma chave de API diretamente no HTML.
